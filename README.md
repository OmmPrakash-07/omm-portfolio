# Omm Portfolio

A modern, responsive, and animated developer portfolio built with **Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide React**.

🌐 **Live Website:** https://omm-portfolio-sigma.vercel.app/

## 🚀 Tech Stack

* **Framework:** Next.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Deployment:** Vercel

## ✨ Features

* Modern developer-focused UI
* Responsive desktop and mobile layouts
* Animated navigation bar with mobile menu
* Hero section with developer introduction
* About section
* Technical skills showcase
* Featured projects with GitHub and live demo links
* Contact section with email and LinkedIn
* Social media links
* Resume PDF integration
* Dark-themed interface with ambient background effects
* Smooth animations and interactive components
* SEO metadata and canonical URL
* Open Graph metadata for social sharing
* Twitter/X card metadata
* Custom social preview image

## ⚙️ Getting Started

### Prerequisites

* Node.js
* npm

### Installation

```bash
git clone https://github.com/OmmPrakash-07/omm-portfolio.git
cd omm-portfolio
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

### Production Build

```bash
npm run build
npm run start
```
