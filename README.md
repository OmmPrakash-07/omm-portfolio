# Omm Portfolio

A modern, animated developer portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## 🚀 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## ✨ Features

- Modern developer-focused UI
- Responsive design
- Smooth animations
- Interactive components
- Project showcase
- Skills section
- Experience and education
- Contact section
- Dark-themed interface
